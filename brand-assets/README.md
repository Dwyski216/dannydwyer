# Brand assets (not part of the website)

The brand kit: style guide, monogram variations and spare font weights.
Kept here, outside `public/`, so they're saved with the project but never
published on the site. The footer monogram the site actually uses
(`DD_CIRCLE_02_LIGHT.png`) stays in `public/`.

`FONTS/` holds the original `.otf` font files. The site serves compressed
`.woff2` copies of five of them from `public/webfonts/` (same letterforms,
smaller downloads); if a font is ever replaced, convert the new `.otf` to
`.woff2` and put it there under the same name.
